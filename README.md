# Buddy Review Landing Page

This is a modern landing page built with [Next.js](https://nextjs.org), utilizing Tailwind CSS for styling and Motion for animations.

## Getting Started

First, install the dependencies if you haven't already:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Motion
- **Integrations:** Google APIs

## Project Structure

- `app/`: Contains the main application routing and pages (e.g., blog, faq, success).
- `public/`: Static assets like images and logos.
- `service/`: Service integrations.

## Features

- Responsive modern design
- Optimized image loading
- Interactive animations
